Expected Complexity
This task is intended to distinguish applications demonstrating advanced technical
achievement.
A successful extension should demonstrate a measurable increase in technical complexity
beyond the core application requirements. This may include one substantial feature or
several closely related components that work together to provide significant additional
functionality.
Examples of appropriate extensions include:
● Real-time synchronisation using Firebase (Week 6)
● Location-aware functionality using Maps and Core Location (Week 7)
● Rich media support using audio or video frameworks (Week 8)
● Gesture-based interaction beyond standard interface controls (Week 9)
● Interactive data visualisation using Swift Charts (Week 9)
● AI integration within the applications functionality (Week 10)
● Local notifications driven by user behaviour or application data (Week 10)
● Deep linking between application content (Week 10)
● Integration of multiple iOS frameworks to deliver a cohesive feature.
● Another feature of comparable complexity approved by your teaching staff.
Simply adding additional screens, duplicating existing functionality, or making cosmetic
interface improvements will not satisfy the expectations of this task
